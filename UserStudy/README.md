## Column description

Each sheet contains the same six (unlabeled) columns, in this order:

| Column | Description |
|---|---|
| 1 | Time difference between two inputs of a 4-digit code. |
| 2 | Token number. |
| 3 | Sequence number. |
| 4 | First digit of code to input by user |
| 5 | Second digit of code to input by user |
| 6 | Third digit of code to input by user | 
| 7 | Fourth digit of code to input by user |
| 8 | |
| 9 | First digit of code generated by inputting digit using the token by user |
| 10 | Second digit of code generated by inputting digit using the token by user |
| 11 | Third digit of code generated by inputting digit using the token by user |
| 12 | Fourth digit of code generated by inputting digit using the token by user |
| 13 | |
| 14 | Error in the first digit (0:no error, 1:error, wrong input) |
| 15 | Error in the second digit (0:no error, 1:error, wrong input) |
| 16 | Error in the third digit (0:no error, 1:error, wrong input) |
| 17 | Error in the fourth digit (0:no error, 1:error, wrong input) |
